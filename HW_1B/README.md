# Вариант B — Учебная система анализа движения (Tracking-модуль)
**Sparse LK (Lucas–Kanade) + Dense Farnebäck + маски движения + автоматический отчёт**

---

## 1) Назначение проекта
Этот репозиторий реализует полный учебный пайплайн для анализа движения на видео с несколькими движущимися объектами:

1. Разреженный оптический поток **Lucas–Kanade (LK)**:
   - поиск ключевых точек;
   - трекинг траекторий на ограниченном числе кадров (**50–200**, как в ТЗ);
   - визуализация траекторий на видео и отдельным графиком в координатах кадра.

2. Плотный оптический поток **Farnebäck**:
   - построение поля движения;
   - выделение движущихся областей через модуль потока (magnitude);
   - получение бинарной маски движения;
   - выделение объектов через компоненты связности и bounding boxes.

3. **Автоматизация отчёта**:
   - метрики ошибок и устойчивости считаются автоматически;
   - графики сохраняются автоматически;
   - итоговый `report.md` генерируется автоматически после каждого запуска.

## 4) Реализация методов (что делает код)

### 4.1 Разреженный поток LK (src/lk_tracker.py)
1) **Детекция точек**:
   - `cv2.goodFeaturesToTrack(gray, ...)` (Shi–Tomasi).
2) **Трекинг**:
   - `cv2.calcOpticalFlowPyrLK(prev_gray, gray, p_prev, ...)`.
3) **(Опционально) Forward–Backward check**:
   - трекаем вперёд (t→t+1), затем назад (t+1→t),
   - точки с большой FB-ошибкой выбрасываются.
4) **Re-detect / replenishment**:
   - если активных точек мало — добавляем новые.
5) **Визуализация**:
   - линии треков + точки поверх исходного кадра,
   - сохраняем видео `lk_tracks.mp4`,
   - сохраняем график `trajectories_plot.png`.

> Важно: LK **не “выделяет человека”**, он отслеживает **углы и текстуру**.  
> Поэтому при богатой текстуре может казаться, что “тречится всё”. Это нормально для LK и отдельно обсуждается в отчёте.

---

### 4.2 Плотный поток Farnebäck (src/farneback_flow.py)
1) **Плотный поток**:
   - `cv2.calcOpticalFlowFarneback(prev, curr, ...)` → поле (fx, fy).
2) **Magnitude**:
   - `mag = sqrt(fx^2 + fy^2)` — интенсивность движения.
3) **Маска движения**:
   - threshold по `mag`:
     - либо фиксированный `--fb-mag-thr`,
     - либо авто по перцентилю `--fb-mag-percentile`.
4) **Морфология**:
   - `OPEN` убирает шум,
   - `CLOSE` склеивает фрагменты и закрывает дырки.
5) **Компоненты + bbox**:
   - `connectedComponentsWithStats`,
   - фильтрация по площади `--fb-min-area`.
6) **Визуализации**:
   - `flow_hsv.mp4` - направление/модуль потока в HSV,
   - `motion_mask.mp4` - наложение маски движения,
   - `motion_boxes.mp4` - bbox по компонентам.

## 5) Автоматизация отчёта (как работает report.md)
После каждого запуска `python src/run_all.py ...` проект автоматически:

1) Сохраняет видео-артефакты:
   - LK треки (`lk_tracks.mp4`)
   - HSV-поток (`flow_hsv.mp4`)
   - маска (`motion_mask.mp4`)
   - bbox (`motion_boxes.mp4`)
2) Считает метрики:
   - LK: удержание точек, forward-backward error (если включено), длины треков
   - Farnebäck: доля движения (`motion_ratio`), фрагментация (`n_components`), доля крупнейшей компоненты, шум-прокси
3) Строит графики и сохраняет в `outputs/<run>/plots/`.
4) Генерирует итоговый **markdown-отчёт**:
   - `outputs/<run>/report.md`,
   - со сводкой результатов + выводами “когда LK / когда Farnebäck”.
